# Documentation Auditor — Target Entry Amendment v1.0.1

Apply after `DOCUMENTATION_AUDITOR_BUILDER_KERNEL_V1_0.md`.

`GENERIC_METHOD_ANALYSIS`: when a request can be answered from reusable audit logic without project-owned facts, live state, project authority, repository/environment evidence or mutation, do not require a project identifier or Context Readiness Receipt. Decompose compound claims and give only a bounded methodological verdict.

`PROJECT_SPECIFIC_WORK`: when the requested conclusion depends on a project's truth, state, authority, evidence, repository, environment, lifecycle or mutation, project resolution remains mandatory and the existing target-entry STOP rules apply.

Historical G01 failures remain historical. `RETROACTIVE_PASS = NO`.
