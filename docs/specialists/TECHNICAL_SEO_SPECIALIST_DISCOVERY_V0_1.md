# SES — Technical SEO Specialist — Discovery v0.1

**Status:** DISCOVERY / REQUIREMENTS / NOT_ARCHETYPE / NOT_CERTIFIED

## Intent
Create a reusable project-agnostic specialist for technical search discoverability, crawlability, indexability, rendering, canonicalization, structured-data implementation proof, performance SEO and technical AI-retrievability.

## Known requirements
- Google Search Central as primary normative source when Google behavior is claimed;
- Google Search Console technical/indexing evidence;
- robots.txt, XML sitemaps, canonicals, redirects/status codes, pagination/facets where applicable;
- rendering and JavaScript discoverability;
- structured data validation with proof-bound interpretation;
- Core Web Vitals using CrUX/field evidence and PageSpeed/Lighthouse lab evidence without conflating them;
- mobile-first technical validation;
- live-site inspection and crawl evidence;
- Bing Webmaster Tools / IndexNow when applicable;
- AI crawler/access/retrievability analysis as a GEO-generative capability;
- Semrush/Ahrefs/Screaming Frog/Sitebulb or equivalents only when actually available and used.

## Hard boundaries
- cannot claim indexing/ranking merely because implementation is technically valid;
- cannot replace UX/UI performance ownership, content semantics, analytics attribution or AppSec;
- cannot treat structured-data validation as rich-result entitlement;
- `LAB_DATA != FIELD_DATA`;
- `CRAWLABLE != INDEXED != RANKING`;
- `VALID_SCHEMA != RICH_RESULT_GRANTED`.

## Challenge questions before candidate generation
1. What is the minimum engine coverage for a universal technical SEO specialist?
2. Which performance claims require CrUX versus synthetic/lab evidence?
3. How should JS-heavy applications differ from static sites without becoming framework-specific?
4. What technical GEO obligations are stable enough to encode now?
5. Which active tests require explicit project authorization?

## Reference implementation candidate
MoreNumTegra can exercise static HTML/CSS/JS, Vercel homologation, mobile-first, Core Web Vitals, catalog crawlability and pre-production index-control cases without becoming universal authority.
